# 扫矿雷达 / scan-mine-radar

可复用的只读调研提示词，用来维护一块多桶加密收益机会看板：交易所理财、链上供应、循环/套息、Merkl、短债价差。只做研究与汇报，不做交易、不签名、不代发。

A reusable read-only research prompt for a multi-bucket crypto yield opportunity board: CEX earn, on-chain supply, loop/carry, Merkl, and short-duration discounts. It researches and reports. It does not trade, sign, or post.

完整规格：[INVESTMENT_OPPORTUNITY_BOARD_PROMPT.md](./INVESTMENT_OPPORTUNITY_BOARD_PROMPT.md)

## 接到代理或例行任务

1. 把 `INVESTMENT_OPPORTUNITY_BOARD_PROMPT.md` 设为代理说明，或设为定时例行的正文（整份，或按桶拆成只读任务）。
2. 只允许公开网页和公开 API。
3. 交付物是一块可筛选的机会看板；聊天里只留一两句结论，并附看板链接。

## Attach it to an agent or routine

1. Set `INVESTMENT_OPPORTUNITY_BOARD_PROMPT.md` as the agent instructions, or as the body of a scheduled routine (the whole file, or one read-only routine per bucket).
2. Allow public pages and public APIs only.
3. Deliver one filterable opportunity board. Keep chat to a one- or two-sentence takeaway plus the board link.

## 对外分享前删掉

- 钱包地址
- 私人 canvas / store 链接
- 个人入金规模
- 社交账号
- 内部代理名称
- 账户专属 vault ID

保留公开协议名、产品名和公开文档链接。

## Strip before you share

- Wallet addresses
- Private canvas or store URLs
- Personal deposit sizes
- Social handles
- Internal agent names
- Account-specific vault IDs

Keep public protocol names, product names, and public documentation URLs.
